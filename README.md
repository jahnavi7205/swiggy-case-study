# swiggy-case-study
swiggy sales analysis
📌 Project Overview

This project analyzes Swiggy order data using Microsoft SQL Server to explore order patterns, pricing distribution, restaurant performance, and customer ratings. SQL queries are used to extract meaningful insights and answer business-related questions.

🎯 Project Objectives

Analyze order distribution across different price ranges.
Identify popular food categories and restaurant performance.
Explore customer ratings and average ratings.
Examine sales trends and order patterns.
Practice SQL queries to solve real-world business problems.

🛠️ Tools & Technologies
Microsoft SQL Server
GitHub

📊 SQL Concepts Used
SELECT, WHERE, ORDER BY
Aggregate Functions: COUNT(), SUM(), AVG(), MIN(), MAX()
GROUP BY and HAVING
CASE Statements
Data Validation and Cleaning
JOINs and Subqueries (where applicable)
Common Table Expressions (CTEs) and Window Functions (where applicable)

🔍 Business Questions
How many orders fall into each price range?
Which food categories receive the most orders?
What is the average rating across restaurants?
Which restaurants perform well based on available order data?
What patterns can be identified from the order data?

💡 Key Learnings

Practiced writing SQL queries to analyze business data.
Used aggregation and grouping to summarize order information.
Applied conditional logic to categorize prices.

Improved data analysis and problem-solving skills.
